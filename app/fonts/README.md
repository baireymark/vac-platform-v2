# Fonts

A self-hosted copy of the latin file Google Fonts served for this site, loaded with `next/font/local` in `app/layout.jsx`.

| File | Family | Source |
| --- | --- | --- |
| `Montserrat-latin.woff2` | Montserrat (variable, used at 500/600/700/800/900) | fonts.gstatic.com/s/montserrat/v31 |

It is licensed under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows self-hosting.
Only the latin subset is included; other characters fall back to the system fonts listed in `app/globals.css`.
